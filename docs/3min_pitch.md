# AI Closet｜3分ピッチ原稿（日本語）

**想定時間：3分 / 6枚**  
**カテゴリー：クリエイティブ**

> デザイン方針：白背景、アクセントはアプリUIと合わせて紫。1枚につき主張は1つ、文字は最大30〜35語程度に抑える。アプリ画面を見せられる箇所は、文章よりスクリーンショットを優先する。

---

## 1. 表紙｜「持っているのに着ていない」を、ゼロにする（0:00–0:15）

### スライドに置くもの

- ロゴ / プロダクト名：**AI Closet**
- メインコピー：**持っているのに着ていない服を、ゼロにする。**
- サブコピー：画像解析で、あなたのクローゼットを「着るための資産」に変える
- 右側：アプリのホーム画面スクリーンショット

### 話すこと

「毎朝、『着る服がない』と思うことはありませんか。実は服がないのではなく、持っている服を把握できず、活かし切れていないことが原因です。私たちはAI Closetで、クローゼットを着るための資産に変えます。」

---

## 2. 課題｜服はあるのに、選べない・振り返れない（0:15–0:40）

### スライドに置くもの

中央に大きく：**「服はある。でも、着る服がない。」**

その下に3点だけ。

- 持っている服や、最近着た服を思い出せない
- コーデ記録は手入力が面倒で続かない
- 似た服を買い、眠っている服に気づけない

### 話すこと

「クローゼットの中身を把握するのは難しく、コーデを記録しようとしても、服名を毎回入力するのは続きません。結果として同じ服に偏り、着ていない服はタンスの奥に眠ったままになります。」

---

## 3. 解決策｜1枚の自撮りから、着用記録を数タップで（0:40–1:10）

### スライドに置くもの

横並びの3ステップ。

1. **登録**：服を撮って、自分だけのクローゼットをつくる
2. **記録**：今日の自撮りをAIが解析し、登録服から候補を提示
3. **発見**：カレンダー・統計で偏りと眠っている服を見つける

下部の強調：**AIは自動確定しない。最後に選ぶのはユーザー。**

### 話すこと

「AI Closetは、服を写真で登録し、着用時は自撮りを1枚撮るだけです。AIがトップスやボトムスの属性を読み取り、自分のクローゼットから候補を提示します。ユーザーが確認するだけで、記録と振り返りが積み上がります。」

---

## 4. デモ｜AIが“探す”、人が“選ぶ”（1:10–1:55）

### スライドに置くもの

アプリの画面を大きく3枚。矢印でつなぐ。

1. 今日の服を撮影
2. AI解析 + 候補カード（最大3件）
3. カレンダー / 着用傾向

小さく添える：

- カテゴリ・色・種類・丈を構造化して照合
- 同じような服でも、候補写真を見て選べる
- 候補がなければ手動選択・新規登録へ進める

### 話すこと

「ここが体験の中心です。自撮りをアップロードすると、AIは服のカテゴリ、色、種類、丈を構造化して取得します。その結果から自分の登録済み服を候補として並べます。誤認識があっても、AIは勝手に記録せず、ユーザーが候補写真を見て選びます。だから、便利さと信頼性を両立できます。」

> **デモを入れる場合**：ここで20秒以内に「撮影 → 候補選択 → カレンダー反映」だけを実演する。実演するならこのスライドの説明は短くして、合計45秒以内に収める。

---

## 5. Google技術｜個人の服と画像を、安全にAI体験へ（1:55–2:25）

### スライドに置くもの

中央にシンプルな流れ。

`Next.js` → `Firebase App Hosting` → `Cloud Run` → `Cloud SQL / Cloud Storage / Vertex AI Gemini`

下に3点。

- **Vertex AI Gemini**：自撮りから服の属性を構造化抽出
- **Cloud SQL**：着用ログを集計し、未着用服・偏りを可視化
- **Firebase Auth + Cloud Storage**：ユーザーごとに画像とデータを分離

### 話すこと

「Google技術をプロダクトの中核にしています。Vertex AI Geminiが画像から服の属性を抽出し、Cloud Runが候補検索と検証を担当します。Cloud SQLには着用履歴を蓄積し、Cloud Storageには画像をユーザー単位で安全に保管します。AIの出力はサーバー側で検証し、本人の服だけを候補にします。」

---

## 6. 未来 / 締め｜服を“所有”から“活用”へ（2:25–3:00）

### スライドに置くもの

中央に大きく：**服を、もっと自分らしく活かせる毎日へ。**

その下に3つの成果。

- 毎朝の「何を着る？」を減らす
- 自分の表現の幅を広げる
- 眠っている服を活かし、無駄な買い足しを減らす

最後に：**AI Closet — Wear what you already love.**

### 話すこと

「AI Closetは、服を増やすためのアプリではありません。すでに持っている服を知り、着て、もっと自分らしい表現につなげるアプリです。『持っているのに着ていない』をゼロにする。AI Closetです。」

---

## 発表時の注意

- スライド5は“技術名の羅列”にせず、Google技術が体験をどう成立させているかを言う。
- AI精度を誇張しない。**候補提示 + ユーザー確認**を安全性・信頼性として一貫して強調する。
- カテゴリーは「クリエイティブ」。ファッションを自己表現・記録・発見として支援する点を一言添える。
- 画面がまだ実データで安定しない場合は、スライド4を録画GIFまたは連続スクリーンショットにしてデモ失敗を避ける。
